# Example monorepo

A small made-up monorepo used for the example output in the top-level README. The files are written to show what `asitis loads` reports: a CLAUDE.local.md that switches off the AGENTS.md fallback, an import that loads nothing, Codex's 32 KiB cut, a nested CLAUDE.md and a path rule.

It is not part of the package and is not linted in CI.
