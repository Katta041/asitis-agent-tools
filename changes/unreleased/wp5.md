### Added
- Skill folder security scan, opt-in with `include: ["skills"]` (`lint_steering`) or `--include skills` (CLI). For every SKILL.md it lints, it walks the skill's folder and reads scripts (`.sh`, `.py`, `.js`, `.ps1` and the rest of the F8 list, plus files without an extension that start with `#!`) up to 1 MB each, and only the first 4 bytes of every other file. `.env` files and symlinks that leave the project are refused. Nothing is run and nothing is sent anywhere; messages quote at most 80 characters of file text, with keys redacted.
- Rules: `sec-remote-exec` (download piped to a shell, `bash -c "$(curl ...)"`, download then run within 5 lines, password-protected archives, quarantine removal), `sec-encoded-blob` (decode piped to a shell or passed to exec, and base64, hex, `\x` and `fromCharCode` text that decodes to a command or an instruction, shown decoded), `sec-secret-egress` (ssh keys, cloud credentials, keychain or wallets read in a script that also sends data out; `.env` and `gh auth token` only on the same line), `sec-skill-network` (a note listing the hosts a script calls), `sec-skill-allowed-tools` (unscoped `Bash`, `*`, any interpreter or unscoped `WebFetch` in `allowed-tools`; a note for subagents with no `tools` list), `sec-skill-binary` (ELF, Mach-O, PE and WebAssembly headers, including binaries named like text files), `sec-safety-off` (`--dangerously-skip-permissions`, `bypassPermissions`, Codex and Gemini `--yolo`, `danger-full-access`, `--trust-all-tools`; a negated sentence does not fire).
- New rules beyond the reserved ids: `sec-skill-arg-injection` (a skill argument such as `$ARGUMENTS` inside a `` !`command` `` or ```` ```! ```` block, which Claude Code fills in before running the command, so `x; other-command` runs too), `sec-script-instruction` (comments or strings in a script that tell the agent to hide something from the user or ignore its instructions) and `sec-script-invisible` (bidi controls, tag characters and variation-selector payloads in scripts).
- `sec-remote-exec` is an error in scripts and the SKILL.md body, and a note in README.md and other markdown in the skill folder, where vendor install snippets live.
- The skill scan also checks `.claude/commands/*.md` (allowed-tools and arguments in injected commands) and `.claude/agents/*.md` (no tools list, `bypassPermissions`).
- A notice after the findings says how many skill folders and files were scanned, and lists files skipped for size, refused symlinks and caps (500 files per skill folder, 5,000 per run, 8 folder levels).
