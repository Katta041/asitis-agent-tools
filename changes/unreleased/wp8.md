### Added
- A documentation page for every active rule in `docs/rules/<rule-id>.md`, with an index in `docs/rules/README.md` grouped by category. Each page has what the rule catches, why it matters, a bad and a good example, how to fix it, how to suppress or configure it (security rules cannot be suppressed inline), and the vendor page or incident it rests on with the date it was read. SARIF `helpUri` values (`https://asitis.app/rules/<rule-id>`) resolve to these pages.
- `packages/mcp/scripts/gen-rule-docs.mjs` generates the pages from the rule registry and the hand-written examples in `packages/mcp/scripts/rule-docs/<rule-id>.md`. `--check` exits 1 when the pages are out of date. Planned rules get no page; an active rule without examples fails the run and names the rule.
- `test/rule-docs.test.ts`: every active rule has a page with all seven sections and a Source link, no page has em-dashes or emoji, SARIF `helpUri` slugs match the page names, and the generated output on disk is current.
