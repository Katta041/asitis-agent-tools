# Project instructions

## Commands

- Run `pnpm test` before every commit.
- Run `pnpm lint` before opening a pull request.
- Use TypeScript strict mode in every package.
- Keep pull requests under 400 changed lines.
- Write a changelog entry for every user-facing change.
- Prefer named exports over default exports.
- Never commit generated files under dist/.
- Ask before adding a new runtime dependency.
